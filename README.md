# cosmo-net

Веб-сервис для проектирования устойчивой спутниковой группировки: расчёт покрытия, сквозных маршрутов до шлюза и сравнение конфигураций. КосмоХакатон 2026.

Группировка из 48 аппаратов на 550 км, три плоскости по 16, запуск тремя очередями. Три северных наземных пункта должны дотянуться до шлюза через спутниковую сеть. Горизонт — сутки, шаг — 120 с, то есть 720 отсчётов. Целевой ориентир — доступность не ниже 90 % для каждого пункта.

## Быстрый старт

```bash
uv sync --extra dev
uv run pytest
uv run uvicorn cosmo_net.serving.api:app --reload
```

Схема API — на `/docs`. Пока фронтенд не собран, корень страницы честно об этом говорит и отправляет в `/docs`.

Пересчитать все показатели, на которые ссылаются документы:

```bash
uv run python scripts/make_report.py
```

## Что уже есть

- Расчётное ядро: положения аппаратов, видимость, межспутниковые связи, состояние сети на сетке времени. Сверено с эталонным модулем организаторов до 1e-13 км.
- Маршрутизация: три стратегии и разбор причины перерыва по четырём категориям.
- Показатели: доступность, видимость, перерывы, переходы — по каждому наземному пункту.
- Анализ: критичность аппаратов, перебор конфигураций с фронтом Парето, сравнение вариантов с диффом параметров.
- HTTP-сервис: загрузка и проверка сценариев, расчёт, снимок сети, сохранение вариантов, выгрузка `cosmo-A-result-1.0`.

Дальше по плану: интерфейс, контейнер, деплой.

## Устройство репозитория

```
src/cosmo_net/
  scenario/   чтение, проверка и запись сценариев cosmo-A-1.0
  geometry/   положения аппаратов и геометрия связей
  routing/    поиск маршрута на одном срезе времени и причина его отсутствия
  analysis/   показатели за горизонт и исследования поверх повторных прогонов
  serving/    HTTP-сервис и хранилище вариантов
scripts/      тонкие точки входа: отчёты, генерация проверочного сценария
tests/        тесты ядра, API и «чужого» сценария
data/         выданные сценарии
reference/    эталонный модуль организаторов, используется в сверочных тестах
reports/      измеренные показатели, на которые ссылается документация
frontend/     интерфейс
```
